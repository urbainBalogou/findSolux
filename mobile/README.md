# MecaDispo — application mobile

Application Flutter (Android en priorité) : trouver un mécanicien ou un garage proche à Lomé, le contacter, envoyer un signal de détresse ; espace garagiste pour gérer sa fiche, ses offres et les demandes reçues.

Identifiant de l'application : `com.mecadispo.app`. Le nom de code technique `findsolux` reste celui du paquet Dart (`package:findsolux/…`).

Démarrage, clés d'API et configuration Google : voir le [README à la racine du dépôt](../README.md).
